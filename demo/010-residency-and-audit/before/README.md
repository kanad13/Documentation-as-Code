# Before

The folder holds the old way: a Word document with a pasted picture. It is the contrast for the demo.

- **Why the files are frozen:**
  - They show what documentation looks like when it lives in Word and PNG.
  - They were exported from the current documents and are never updated, so they drift the moment anything changes.
- **Why they are in Git:**
  - Presenters can open them during demos to contrast the legacy format with documentation as code.

## Contents

- `Northwind-Sales-Insights-Overview-v7-FINAL-2.docx`: The overview as someone would keep it in Word.
- `architecture-diagram.png`: The architecture diagram exactly as it would be pasted into that document.
